Candidate Competitor Categories For Research

These categories are scope hypotheses from existing approved research and repo context, not findings from this competitive-analysis run.

  • General form builders and survey tools used for polished public forms.
  • AI-assisted form generation tools and generic AI form-builder features.
  • Client-service intake, onboarding, and client-portal suites.
  • Automation stacks that connect forms to spreadsheets, CRM, Notion, email, or project tools.
  • Manual alternatives such as email questionnaires, Google Docs, PDF intake packets, and spreadsheet checklists.

Session Loop

  1. This page receives compiled YAML approval for scope and selected frameworks.
  2. The next $competitive-analysis invocation writes the run manifest and runs the first pending framework only.
  3. Each framework emits its own findings review page and stops for compiled YAML approval.
  4. After all selected framework intermediates exist, $competitive-analysis --synthesize or a normal invocation creates the synthesis review page.
  5. Only after final synthesis approval are canonical competitive-analysis files written.
