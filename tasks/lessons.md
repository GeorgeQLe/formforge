# Lessons

- When a skill's default routing suggests a follow-up command, distinguish policy-based routing from evidence-based findings. Do not imply an artifact needs upgrading unless specific drift, stale content, or standard mismatch has been identified and named.
- When replacing canvas/SVG charts with HTML/CSS bars, give the visible fill element an explicit height or flex-backed layout; do not rely on `height: 100%` inside a parent that only has `min-height`.
